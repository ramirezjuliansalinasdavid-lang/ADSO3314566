09-Absolute-Units

Especifique un valor de longitud fijo. No importa si cambia el ancho o la altura de la pantalla.

  • Inch (in)
  • Centimeter (cm)
  • Millimeter (mm)
  • Point (pt)
  • Pica (pc)

🎨 Demostración Visual

  • 0.5in Pulgada - 1in = 2.54cm
  • 1cm Centímetro - Unidad métrica
  • 10mm Milímetro - 10mm = 1cm
  • 10pt Punto - 1pt = 1/72 pulgada
  • 2pc Pica - 1pc = 12pt
