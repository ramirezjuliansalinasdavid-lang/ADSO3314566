20-Pseudoclasses

Se utiliza para definir un estado especial de un elemento.

🎯 ¿Qué son las Pseudoclases?

Una pseudoclase define un estado especial de un elemento. Se escriben con : seguido del nombre de la pseudoclase.

🖱️ :hover

Se activa cuando el mouse pasa sobre el elemento.

✨ Efecto hover ✨
button:hover { background: #7c3aed; transform: scale(1.05); }

👆 :active

Se activa en el momento que se hace clic (elemento presionado).

button:active { transform: scale(0.95); background: #5b21b6; }

⌨️ :focus

Se activa cuando el elemento recibe foco (tab o clic).

input:focus { outline: 2px solid #a855f7; background: #1e1e2e; }

🔗 :link y :visited

:link → enlace no visitado | :visited → enlace ya visitado.

Enlace no visitado (link) Enlace visitado (visited)
a:link { color: #a78bfa; }
a:visited { color: #c084fc; }

👶 :first-child / :last-child

Selecciona el primer o último hijo de un contenedor.

📦 Primer hijo (first-child)
📦 Hijo del medio
📦 Último hijo (last-child)
.child-item:first-child { background: #7e22ce; }
.child-item:last-child { background: #4c1d95; }

🔢 :nth-child(n)

Selecciona elementos según su posición (par, impar, número específico).

Elemento 1
Elemento 2
Elemento 3
Elemento 4
Elemento 5
Elemento 6
🎨 :nth-child(even) - Pares 🎨 :nth-child(odd) - Impares 🎨 :nth-child(3n) - Múltiplos de 3
.nth-item:nth-child(even) { background: #6d28d9; }
.nth-item:nth-child(odd) { background: #8b5cf6; }

🚫 :not()

Selecciona todos los elementos EXCEPTO los que coinciden con el selector.

✨ Especial (excluido)
Normal 1
Normal 2
Normal 3
.not-item:not(.especial) { background: #4c1d95; }
