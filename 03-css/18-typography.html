18-Typography

  • Color
  • Family
  • Size
  • Weight

    • 🎨 COLOR

    Define el color del texto. Puede usar nombres, hexadecimales, RGB, HSL.

    ❤️ #ff6b6b - Rojo coral

    💚 #4ecdc4 - Verde menta

    💛 #ffe66d - Amarillo

    💜 #c9b3ff - Lavanda (tu paleta)

    💙 rgb(139, 92, 246) - Morado

    🔤 FAMILY

    Define la fuente o tipo de letra del texto.

    Sans-Serif: Arial, Helvetica, sans-serif

    Serif: Georgia, Times, serif

    Monospace: 'Courier New', monospace

    Cursive: 'Brush Script MT', cursive

    font-family: 'Poppins', 'Segoe UI', system-ui, sans-serif;

    📏 SIZE

    Define el tamaño del texto (px, em, rem, %).

    10px - Extra pequeño

    14px - Pequeño

    18px - Mediano

    24px - Grande

    32px - Extra grande

    48px - Mega

    💪 WEIGHT

    Define el grosor o negrita del texto (100 a 900).

    100 - Thin (Delgado)

    300 - Light (Ligero)

    400 - Regular (Normal)

    500 - Medium (Medio)

    600 - SemiBold

    700 - Bold (Negrita)

    800 - ExtraBold

    900 - Black (Negro)

    ✨ Ejemplo combinado

    Este texto combina color, font-family, font-size y font-weight

    color: #c9b3ff;
    font-family: 'Poppins', sans-serif;
    font-size: 1.2rem;
    font-weight: 600;

    📋 Propiedades de Typography

    Propiedad Descripción Ejemplo
    color Color del texto color: #663399;
    font-family Tipo de fuente font-family: 'Arial', sans-serif;
    font-size Tamaño del texto font-size: 16px;
    font-weight Grosor del texto font-weight: bold;
    font-style Estilo (normal/italic) font-style: italic;
    text-align Alineación del texto text-align: center;
