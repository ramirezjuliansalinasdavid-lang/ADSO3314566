23-Sprite

Un sprite de imagen es una colección de imágenes agrupadas en una sola imagen.

🎯 ¿Qué es un Sprite?
Un sprite es una única imagen que contiene múltiples frames o gráficos. Se usa para animaciones, iconos y juegos, ya que reduce las peticiones al servidor y mejora el rendimiento. Mediante background-position mostramos un frame diferente en cada momento.
🎬 Sprite 1 - Animación principal 6 frames
📐 Tamaño: 256×256px
🎞️ Frames: 6
⚡ Velocidad: 80ms
⚙️ Intervalo actual: 80ms
/* Código CSS del Sprite */
background: url(img/anim-sprite.png) no-repeat;
background-position: calc(-256px * n) 0;
/* n = 0,1,2,3,4,5 para cada frame */
🎨 Sprite 2 - Segunda animación 5 frames
📐 Tamaño: 320×400px
🎞️ Frames: 5
⚡ Velocidad: 65ms
⚙️ Intervalo actual: 65ms
/* Código CSS del Sprite 2 */
background: url(img/sprite.png) no-repeat;
background-position: calc(-320px * n) 0;
/* n = 0,1,2,3,4 para cada frame (5 frames) */
