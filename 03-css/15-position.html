    • 📌STATIC (Normal)

    Position: Static
    Elemento Static
    ⚡Flujo normal

    No se mueve sigue el flujo del documento. es el valor por defecto

    🔍"Static"es el posicionamiento por defecto. Los elementos se colocan en orden normal (uno debajo de otro). Las propiedades top, right, bottom, left NO afectan a un elemento static.

    🔁RELATIVE

    position: relative; top: 20px; left: 30px;
    Relative
    ⚡ Se desplaza

    ✨ ¡Observa cómo se mueve 20px hacia abajo y 30px a la derecha! pero respeta su espacio original.

    📐 Relative: Se desplaza respecto a su posición normal, pero el espacio original queda reservado. Es útil para ajustes finos o como contenedor de elementos absolute.

    🎯 ABSOLUTE

    position: absolute; bottom: 15px; right: 20px;

    📦 Contenedor relative (padre)

    Absolute
    ⚡ Anclado abajo-derecha

    ⬅️ Este elemento se posiciona respecto al contenedor con position: relative.

    📍 Absolute: Se saca del flujo normal y se posiciona respecto a su ancestro posicionado más cercano (relative, absolute, fixed, sticky). Si no existe, se posiciona respecto al <html>. Ideal para modales, tooltips o elementos superpuestos.

    📌 FIXED

    position: fixed; bottom: 20px; right: 20px;
    💡 Fixed se posiciona respecto a la ventana del navegador (viewport).
    Un elemento con position: fixed permanece en el mismo lugar aunque hagas scroll en la página.
    ⭐ ¡Mira la esquina inferior derecha de la PÁGINA! (Hay un cuadro fijo real)
    🧱 Fixed: Se queda "pegado" a la pantalla siempre visible. No se mueve al hacer scroll. Es típico para menús flotantes, botones de acción, o chats. En este ejemplo hemos creado un recuadro fijo real abajo a la derecha (usa scroll para comprobarlo).

    🧲 STICKY

    position: sticky; top: 0;
    📌 Soy un encabezado STICKY (¡desliza hacia abajo!)
    🧾 Contenido desplazable...
    Al hacer scroll, el elemento "sticky" se pega arriba hasta que su contenedor termina.
    Más contenido para ver el efecto sticky.
    🧲 Sticky: Híbrido entre relative y fixed. Se comporta como relative hasta que su contenedor lo lleva al borde establecido (top:0), entonces se "pega" como fixed dentro de su contenedor padre. Ideal para headers de sección o tablas.
