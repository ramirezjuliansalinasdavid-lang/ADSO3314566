08-Relative-Units

Especifique una longitud relativa a otra propiedad de longitud

  • Pixel (px)
  • M (em)
  • X (ex)
  • Root M (rem)
  • Viewport height (vh)
  • Viewport width (vw)
  • Large viewport (lvh | lvw)
  • Small viewport (svh | svw)
  • Dynamic viewport (dvh | dvw)

🎨 Demostración Visual

  • 15px Pixel - Unidad absoluta, no escala con el navegador
  • 1.5em Em - Relativo al tamaño de fuente del elemento padre
  • 2rem Rem - Relativo al tamaño de fuente del elemento raíz (html)
  • 2.4ex Ex - Relativo a la altura de la letra 'x' minúscula
