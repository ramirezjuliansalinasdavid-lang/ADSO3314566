22-Cursors

Especifica el cursor del ratón que se mostrará al apuntar sobre un elemento.

🖱️ ¿Qué es la propiedad cursor?

La propiedad cursor especifica el tipo de cursor del ratón que se mostrará al pasar sobre un elemento. Mejora la experiencia del usuario indicando qué acción se puede realizar.

🔹 Cursor: auto | default | none

auto

El navegador determina el cursor

default

Cursor por defecto (flecha)

none

Sin cursor (oculto)

🔗 Cursor: pointer | context-menu | help

pointer

Mano - indica enlace clickeable

context-menu

Menú contextual disponible

help

Ayuda/información disponible

⏳ Cursor: progress | wait

progress

En progreso (puede interactuar)

wait

Espera (cargando, no interactuar)

✏️ Cursor: text | vertical-text | crosshair

text

Seleccionar texto (cursor I)

vertical-text

Texto vertical

crosshair

Precisión (selección exacta)

🖐️ Cursor: move | grab | grabbing | all-scroll

move

Mover elemento

grab

Agarrar (mano abierta)

grabbing

Arrastrando (mano cerrada)

all-scroll

Desplazar en todas direcciones

📐 Cursor: redimensión (ew-resize, ns-resize, etc.)

ew-resize

Horizontal ↔️

ns-resize

Vertical ↕️

nesw-resize

Diagonal ↗️↙️

nwse-resize

Diagonal ↖️↘️

🔍 Cursor: zoom-in | zoom-out

zoom-in

Acercar (+) → clic

zoom-out

Alejar (-) → clic

🚫 Cursor: not-allowed | no-drop

not-allowed

Acción no permitida

no-drop

No se puede soltar aquí

/* Evita que el usuario haga clic en elementos deshabilitados */
.disabled { cursor: not-allowed; opacity: 0.6; }

📋 Tipos de cursores CSS

Categoría Valores Uso típico
Básicos auto, default, none Comportamiento estándar
Enlaces/Selección pointer, context-menu, help Botones, enlaces, ayuda
Progreso progress, wait Carga de datos, procesos
Texto text, vertical-text, crosshair Selección de texto, precisión
Movimiento move, grab, grabbing, all-scroll Arrastrar, mover elementos
Redimensión ew-resize, ns-resize, nesw-resize, nwse-resize Cambiar tamaño de elementos
Zoom zoom-in, zoom-out Ampliar/reducir contenido
Prohibido not-allowed, no-drop Elementos deshabilitados
