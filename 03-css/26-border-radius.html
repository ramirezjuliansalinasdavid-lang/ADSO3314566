📐 Border Radius - Demostración

La propiedad border-radius define el radio de las esquinas del elemento. Arrastra los sliders para ver cómo cambia el borde en tiempo real.

20px

🎨 Ejemplos de diferentes valores

border-radius: 20px; 1 valor - Misma curvatura en todas las esquinas
border-radius: 30px 10px; 2 valores - Diagonal opuesta
border-radius: 30px 10px 50px; 3 valores - Superior izquierda, superior derecha e inferior izquierda, inferior derecha
border-radius: 10px 30px 50px 70px; 4 valores - Cada esquina independiente (arriba-izq, arriba-der, abajo-der, abajo-izq)
border-radius: 50%; Porcentaje - Forma circular/elíptica
border-radius: 40px / 20px; Elípticas - Radio horizontal/vertical diferentes
