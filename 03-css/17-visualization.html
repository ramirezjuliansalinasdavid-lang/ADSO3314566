17-Visualization

  • Display: block|inline|none|flex|grid
  • Visibility: visible|hidden
  • Overflow: visible|hidden|scroll|auto
  • Z-Index: 1...n

    • 🎨 DISPLAY

    Define cómo se comporta un elemento en el flujo del documento.

    block
    Ocupa todo el ancho
    inline inline Solo ocupa su contenido
    none
    ¡No se ve ni ocupa espacio!
    flex
    Layout flexible
    grid
    Layout en cuadrícula

    👁️ VISIBILITY

    visible
    hidden
    visible

    💡 visibility: hidden → oculta el elemento PERO sigue ocupando espacio

    💡 display: none → oculta y NO ocupa espacio

    📦 OVERFLOW

    visible
    Lorem ipsum dolor sit amet consectetur adipisicing elit. Este contenido se desborda y se ve fuera de la caja.
    hidden
    Lorem ipsum dolor sit amet consectetur adipisicing elit. Este contenido se desborda pero queda oculto.
    scroll
    Lorem ipsum dolor sit amet consectetur. Aparecen barras de scroll siempre.
    auto
    Lorem ipsum dolor sit amet consectetur. Solo muestra scroll si es necesario.

    🔢 Z-INDEX

    z-index: 1
    z-index: 2
    z-index: 3

    🎯 Mayor z-index = más cerca del usuario (se superpone arriba)

    ⚠️ Solo funciona en elementos con position (relative, absolute, fixed, sticky)

    📋 Resumen de propiedades

    Propiedad Valores ¿Ocupa espacio?
    display block, inline, none, flex, grid none = no | otros = sí
    visibility visible, hidden Sí (hidden mantiene el espacio)
    overflow visible, hidden, scroll, auto Controla desbordamiento
    z-index 1, 2, 3... n Controla superposición
