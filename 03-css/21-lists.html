📋 ¿Qué son las propiedades de listas?

CSS permite configurar el estilo de las listas (ul, ol) incluyendo el tipo de viñeta, posición y usar imágenes personalizadas.

🎯 LIST-STYLE-TYPE

Define el tipo de viñeta o numeración de la lista.

  • Elemento 2

  • none (sin viñeta)

  • Elemento 3

📍 LIST-STYLE-POSITION

Define la posición de la viñeta (dentro o fuera del contenido).

outside (fuera - por defecto)

  • Lorem ipsum dolor sit amet consectetur adipisicing elit. La viñeta está fuera del texto.
  • Elemento 2 con texto más largo para mostrar la diferencia

inside (dentro)

  • Lorem ipsum dolor sit amet consectetur adipisicing elit. La viñeta está dentro del texto y se alinea con el contenido.
  • Elemento 2 con texto más largo para mostrar la diferencia

🖼️ LIST-STYLE-IMAGE

Usa una imagen personalizada como viñeta.

  • Viñeta con imagen personalizada (⭐)
  • Elemento 2 con viñeta personalizada
  • Elemento 3 con viñeta personalizada
list-style-image: url('estrella.png');

⚡ LIST-STYLE (Shorthand)

Propiedad resumida que combina type, position e image.

list-style: square inside;

  • Elemento 1
  • Elemento 2
  • Elemento 3

list-style: upper-roman outside;

  • Elemento 1
  • Elemento 2
  • Elemento 3

list-style: none;

  • Sin viñetas
  • Útil para menús
  • Se usa con padding:0
/* Formato: list-style: type position image; */
list-style: square inside;
list-style: none; /* Elimina viñetas */

🍔 Listas horizontales (Menús)

Combinando list-style: none y display: inline-block.

📋 Propiedades de Listas

Propiedad Valores comunes Descripción
list-style-type disc, circle, square, decimal, lower-roman, upper-alpha, none Tipo de viñeta o numeración
list-style-position outside, inside Posición de la viñeta
list-style-image url('imagen.png'), none Imagen como viñeta
list-style type position image
