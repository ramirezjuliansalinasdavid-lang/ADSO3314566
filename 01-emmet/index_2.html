Anidar Elementos

Operador: >
ul>li>a 
<ul>
    <li><a href="">Enlace</a></li>
</ul>
Perfecto para crear menús de navegación anidados

Elementos Hermanos

Operador: +
section+header+nav 
<section></section>
<header></header>
<nav></nav>
Crea múltiples elementos al mismo nivel

Repetir Elementos

Operador: *
ul>li*3 
<ul>
    <li></li>
    <li></li>
    <li></li>
</ul>
Crea 3 elementos li de una sola vez

Atributo Clase

Operador: .
div.contenedor 
<div class="contenedor"></div>
Si no especificas etiqueta, por defecto es <div>

Identificador ID

Operador: #
nav#menu 
<nav id="menu"></nav>
Útil para identificar elementos únicos

Agregar Texto

Operador: {}
a{Click Aquí} 
<a href="">Click Aquí</a>
Añade contenido de texto directamente

Números Consecutivos

Operador: $
ul>li.item$*3 
<ul>
    <li class="item1"></li>
    <li class="item2"></li>
    <li class="item3"></li>
</ul>
Los $$ dan 01, 02, etc. Los $$$ dan 001, 002...

Subir de Nivel

Operador: ^
section>article>div^p 
<section>
    <article>
        <div></div>
    </article>
    <p></p>
</section>
Cada ^ sube un nivel en la jerarquía

Agrupar Elementos

Operador: ()
(header>nav)+(section>article) 
<header>
    <nav></nav>
</header>
<section>
    <article></article>
</section>
Útil para agrupar estructuras complejas
